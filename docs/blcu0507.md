# 另一个斐波那契问题

[https://oj.internal.blcujszx.cn/problems/2120778016989339649]()

题目要求要在 $S$ 中选出 $k$ 个数构成一个新的斐波那契数列

首先考虑 $S$ 中最小的两个数：$4, 6$

显然

$4 = 2F_3$，$6 = 2F_4$

我们构造一个新的斐波那契数列

$F'_1 = 4$，$F'_2 = 6$

根据斐波那契数列的定义

$F_i = F_{i-1} + F_{i-2}$

则对于任意一个 $i \gt 3$ 有：

### $F_{i-1} \lt F_i \lt 2F_{i-1}$

即

### $\frac{1}{2}F'_{i-3} \lt F_i \lt F'_{i-3}$

而

$\frac{F_{i-1}}{F_i} \approx 0.618$

$F'_{i-4} \approx 0.618F'_{i-3} = 1.236F_{i-1} \lt 1.618F_{i-1} \approx F_i$

因此

### $F'_{i-4} \lt F_i \lt F'_{i-3}$

而对于任何一个 $i$ 有

$F_{i+3} \approx 1.618F_{i+2} \lt F'_i = 2F_{i+2} \lt 2.618F_{i+2} \lt F_{i+4}$

故

$F'_i \neq F_j$，$i, j \in \mathbb{N}^*$

$k = \max\{n-4, 0\}$

## 参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
typedef long long ll;

ll n;
signed main(){
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    cin>>n;
    cout<<max(n-4,0);
    return 0;
}
```
