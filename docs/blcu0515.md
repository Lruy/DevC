# 期末复习规则怪谈

[https://oj.internal.blcujszx.cn/problems/2120904839380770817]()

## 题目大意

给定一张 $n$ 个节点 $m$ 条边的有向无环图

定义一次操作如下:

选定一个节点 $i$ , 标记节点 $i$ 和每一个节点 $j$ 满足从 $j$ 出发可达 $i$

求标记全部节点需要的最少操作次数

## 赛时思路

对于每个节点 $i$ , 如果存在边 $i \to j$ , 那么在对 $j$ 操作时 $i$ 也会被一并标记

如果 $i$ 不指向任何一条边 , 那么我们必须对 $i$ 进行一次操作 , 否则 $i$ 不会被任何其他操作标记

记录每个节点的出度, 即指向其他节点的边数, 对每一个出度为 $0$ 的节点进行一次操作即可

时间复杂度 $O(n)$

## 参考代码

```cpp
#include <iostream>
using namespace std;
typedef long long ll;

ll n,m,ans;
ll cd[100005];
signed main(){
    ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
    cin>>n>>m;
    for(int i=0;i<m;i++){
        ll t1,t2;
        cin>>t1>>t2;
        cd[t1]++;
    }
    for(int i=1;i<=n;i++)if(cd[i]==0)ans++;
    cout<<ans<<'\n';
    return 0;
}
```
