# 永除塔扉

[https://oj.internal.blcujszx.cn/problems/2120912961549803521]()

## 赛时思路

非常标准的背包 dp，对每张攻击牌和防御牌跑 $01$ 背包

如有特殊牌，则取其中 $b$ 最高的一张对伤害跑一次完全背包即可

如果 $D_{\max} \ge x$，那么输出 $D_{\max}$

否则，找到格挡 $\ge y$ 中消耗最少能量 $m$ 的方案，输出 $D_{\max - m}$

否则，输出 $-1$

时间复杂度 $O(nm)$

## 参考代码

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;
typedef long long ll;

ll t;
ll dpdmg[5000005],dpdef[5000005]; //对伤害和格挡的dp
signed main(){
    ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
    cin>>t;
    while(t--){
        ll n,m,x,y;
        cin>>n>>m>>x>>y;
        for(int i=0;i<=m;i++){ //初始化
            dpdmg[i]=0;
            dpdef[i]=0;
        }
        ll maxb=0; //最大的特殊牌的b
        ll minm=1e9; //格挡>=y中最少的耗魔量
        for(int i=0;i<n;i++){
            char tt;
            cin>>tt;
            if(tt=='A'){
                ll t1,t2;
                cin>>t1>>t2;
                for(int i=m;i>=t1;i--){
                    dpdmg[i]=max(dpdmg[i],dpdmg[i-t1]+t1*t2); //01背包
                }
            }
            else if(tt=='D'){
                ll t1,t2;
                cin>>t1>>t2;
                for(ll i=m;i>=t1;i--){
                    dpdef[i]=max(dpdef[i],dpdef[i-t1]+t1*t2); //01背包
                    if(dpdef[i]>=y)minm=min(minm,i); //更新minm
                }
            }
            else{
                ll t1;
                cin>>t1;
                maxb=max(maxb,t1); //更新maxb
            }
        }
        if(maxb>0)for(int i=0;i<m;i++)dpdmg[i+1]=max(dpdmg[i+1],dpdmg[i]+maxb); //完全背包
        if(dpdmg[m]>=x)cout<<dpdmg[m]<<'\n'; //按照题意输出
        else{
            if(minm==1e9)cout<<-1<<'\n';
            else cout<<dpdmg[m-minm]<<'\n';
        }
    }
    return 0;
}
```
