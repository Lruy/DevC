# 抓住逃亡奶牛

### 题目描述

农夫约翰得知了一头逃亡奶牛的位置，想要立即抓住她。他起始于数轴上的点 $N$（$0 \le N \le 100,000$），而奶牛位于同一条数轴上的点 $K$（$0 \le K \le 100,000$）。农夫约翰有两种移动方式：

- **步行**：从任意点 $X$ 在一分钟内移动到 $X-1$ 或 $X+1$。
- **传送**：从任意点 $X$ 在一分钟内移动到 $2 \times X$。

如果奶牛保持静止，求抓住奶牛的最短时间（分钟）。

**样例**：$N=5$，$K=17$，最短路径为 `5→4→8→16→17`（或 `5→10→9→18→17`），耗时 $4$ 分钟。

---

## 一、BFS 解法

### 1.1 思路

所有操作代价都是 $1$ 分钟，天然适合 BFS。状态空间 $[0, 200000]$（最远不超过 $\max(N,K) \times 2$），每个状态三种出边。

BFS 的层序性质保证第一个到达 $K$ 的路径就是最短路。

### 1.2 图解

```
从 N=5 出发的 BFS 搜索树（部分）：

                    5 (dist=0)
                 /  |  \
               4    6    10 (dist=1)
             /|\   ...  / | \
            3 5 8      9 11 20 (dist=2)
              ...     /|\
                    8 10 18 (dist=3)
                          |
                         17 (dist=4) ← 找到！输出 4
```

### 1.3 代码

```cpp
#include <iostream>
#include <queue>
using namespace std;
typedef long long ll;

const int MAXN = 200005;

ll n, m;
ll dist[MAXN];

int main() {
    ios::sync_with_stdio(false), cin.tie(0);

    cin >> n >> m;
    fill(dist, dist + MAXN, -1);      // -1 表示未访问

    queue<ll> q;
    q.push(n);
    dist[n] = 0;

    while (!q.empty()) {
        ll x = q.front(); q.pop();

        if (x == m) {                 // 到达目标，立刻输出
            cout << dist[x];
            return 0;
        }

        // 三种移动方式
        ll nx = x - 1;
        if (nx >= 0 && dist[nx] == -1) {
            dist[nx] = dist[x] + 1;
            q.push(nx);
        }

        nx = x + 1;
        if (nx < MAXN && dist[nx] == -1) {
            dist[nx] = dist[x] + 1;
            q.push(nx);
        }

        nx = x << 1;                   // x * 2
        if (nx < MAXN && dist[nx] == -1) {
            dist[nx] = dist[x] + 1;
            q.push(nx);
        }
    }

    return 0;
}
```

### 1.4 复杂度分析

| 维度         | 值                                     |
| ------------ | -------------------------------------- |
| 状态数       | 最多$2 \times 10^5$                  |
| 每条边       | 3 条出边                               |
| 每个状态入队 | **恰好一次**                     |
| 总复杂度     | $O(\max(N,K)) \approx 2 \times 10^5$ |

在 $N, K \le 10^5$ 的数据范围下轻松通过。

---

## 二、反向 DP

### 2.1 思路

BFS 的瓶颈在于状态空间随 $\max(N,K)$ 线性增长。当 $K$ 高达 $10^{18}$ 时，BFS 直接不可行。

换个方向思考——从 $K$ 倒推 $N$。三种正向操作都可以逆过来：

| 正向操作      | 反向操作      | 条件         |
| ------------- | ------------- | ------------ |
| $X \to X+1$ | $X \to X-1$ | $X > 0$    |
| $X \to X-1$ | $X \to X+1$ | 无限制       |
| $X \to 2X$  | $X \to X/2$ | $X$ 为偶数 |

关键在于：反向的 `/2` 只能在偶数上做。这恰好让问题大幅简化。

### 2.2 决策规则

从 $K$ 倒推时，每次面对当前位置 $x$：

- $x \le N$：已在农夫左侧，只能走回去，步数 $N - x$。
- $x$ 为**偶数**：直接 `/2`，步数 $+1$。这总是最优的，因为走几步再 `/2` 的代价不可能更小。
- $x$ 为**奇数**：无法直接 `/2`，必须先走一步到偶数再 `/2$，步数 $+2$。试探 $(x-1)/2$ 和 $(x+1)/2$ 两条路，取更优者。注意取 $x+1$ 时 $(x+1)/2 < x$，所以需要一个纯走路的兜底上界来保证搜索终止。

**证明（偶数直接 `/2` 最优）**：从偶数 $x$ 走 $d$ 步到 $y$，再 `/2` 到 $y/2$，总代价 $d+1$。直接 `/2$ 到 $x/2$，再走 $|y/2 - x/2|$ 步到达同一位置，代价 $1 + |y/2 - x/2|$。因为 $y = x \pm d$，$|y/2 - x/2| \le d/2 \le d$，后者始终不劣。

### 2.3 递归树图解

```
从 K=17 倒推 N=5：

              f(17)              ← 17 奇数
            /   |    \
     f(8)+2    |    f(9)+2       ← 走 ±1 再 /2
      /       f(12)              ← 17-5=12，纯走路兜底
    f(4)+1                       ← 8 偶数，直接 /2
      |
    f(2)+1                       ← 4 偶数，直接 /2
      |
    f(1)+1                       ← 2 偶数，直接 /2
      |
    4-1=3                        ← x=1 ≤ N=5，纯走回

最优：f(17) = min( 3+1+1+1+2, 12 ) = 4 ✓
```

### 2.4 代码

```cpp
#include <iostream>
#include <unordered_map>
#include <algorithm>
using namespace std;
typedef long long ll;

ll n, m;
unordered_map<ll, ll> memo;

ll f(ll x) {
    if (x <= n) return n - x;          // 到达 N 左侧，走回去
    if (memo.count(x)) return memo[x]; // 已计算过，直接返回

    ll ans = x - n;                     // 上界：纯走路

    if (!(x & 1))                       // 偶数 → 直接 /2
        ans = min(ans, 1 + f(x >> 1));
    else {                              // 奇数 → 走 ±1 再 /2
        ans = min(ans, 2 + f((x - 1) >> 1));
        if (x > 1)                      // x=1 时 +1 会回自身，跳过
            ans = min(ans, 2 + f((x + 1) >> 1));
    }

    return memo[x] = ans;
}

int main() {
    ios::sync_with_stdio(false), cin.tie(0);
    cin >> n >> m;
    cout << f(m);
    return 0;
}
```

### 2.5 复杂度分析

| 维度               | 值                                         |
| ------------------ | ------------------------------------------ |
| 每次递归           | $x$ 减半（/2 或 (±1)/2）                |
| 递归深度           | $O(\log K)$                              |
| 分支数             | 偶数时 1 条，奇数时 2 条（且不能同时都走） |
| 总状态数           | $O(\log K)$                              |
| 记忆化             | `unordered_map`，O(1) 查询               |
| **总复杂度** | $O(\log K)$                              |

当 $K \le 10^9$ 甚至 $K \le 10^{18}$ 时，递归深度也不过约 60 层，瞬间完成。

---

## 三、两种解法对比

| 维度     | BFS                   | 反向 DP                                    |
| -------- | --------------------- | ------------------------------------------ |
| 复杂度   | $O(\max(N,K))$      | $O(\log K)$                              |
| 数据范围 | $\le 2 \times 10^5$ | **无上限**（$K$ 可达 $10^{18}$） |
| 实现难度 | 简单                  | 中等                                       |
| 原理     | 边权为 1 的最短路     | 倒推 + 记忆化                              |

---

## 四、总结

1. **BFS 是最直观的解法**：状态空间小，边权为 1，每个状态恰好被访问一次，O(max(N,K)) 即可求解。代码短，不易出错。
2. **反向思考是突破点**：从 K 倒推 N 时，`/2` 只对偶数有效这一限制，使得偶数时直接 `/2` 总是最优——不需要考虑"先走几步再 `/2`"，搜索分支骤减到 O(log K)。
3. **记忆化 DP 把指数级搜索变成了对数级**：每次递归 $x$ 至少减半，深度 $O(\log K)$，配合 `unordered_map` 记忆化，可以处理 $K$ 大到 $10^{18}$ 的极端情况。

> 思考延伸：如果"传送"的代价不是 1 而是 2 呢？如果 N 和 K 之间存在障碍格呢？这些变体都是这道经典题目在 ICPC 和 IOI 中的衍生方向。
