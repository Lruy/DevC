# 转移水晶

[https://oj.internal.blcujszx.cn/problems/2120820296158490626]()

## 题目大意

给定一颗以 $1$ 为根, 包含 $n$ 个节点的树, 边权为 $1$

在 $i$ 处可以花费 $w_i$ 移动到 $i$ 子树中任意节点, 求从 $1$ 开始到每个节点的最短距离

## 赛时思路

我们移动到一个节点 $i$ 有两种方式: 从 $1$ 沿边走到 $i$ , 和在沿途所有节点中选择一个节点 $j$ 花费 $w_j$ 转移到 $i$

首先考虑 $Dijkstra$ , 显然当整棵树是一条长链时需要建 $\frac{n(n-1)}{2}$ 条边, 超出时间要求

其次考虑对整棵树从根向叶子 $DFS$

维护当前深度和路径上 $\min\{depth_i + w_i\}$

对 $DFS$ 到的每个节点 $i$ , 从 $1$ 到 $i$ 的最短距离为两者最小值

时间复杂度 $O(n)$

## 参考代码

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;
typedef long long ll;

ll n;
ll w[200005]; //权重
ll ans[200005]; //最短距离
bool vis[200005]; 
vector<ll> v[200005]; //用邻接表存树
void dfs(ll pos,ll dep,ll tele){
    ans[pos]=min(dep,tele); //到当前节点的最短距离为min( 深度, min(dep[i] + w[i]) )
    vis[pos]=true;
    for(auto p:v[pos]){
        if(!vis[p]){
            dfs(p,dep+1,min(tele,dep+w[pos])); //到下一个节点时, 深度+1
        }
    }
}

signed main(){
    ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
    cin>>n;
    ll t1,t2;
    for(int i=0;i<n-1;i++){
        cin>>t1>>t2;
        v[t1].push_back(t2);
        v[t2].push_back(t1);
    }
    for(int i=1;i<=n;i++)cin>>w[i];
    dfs(1,0,1e9); //初始tele设为极大值 让后续dep[i] + w[i]与极大值取最小值
    for(int i=1;i<=n;i++)cout<<ans[i]<<" ";
    return 0;
}
```
