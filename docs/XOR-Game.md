# XOR Game

### 题目描述

Alice 和 Bob 在玩一个博弈游戏。

桌上有一个多重集 $\{a_i\}$（每个数要么是 $0$，要么是 $2^i$），还有一个初始值为 $0$ 的整数 $x$。两人轮流操作，Alice 先手。每回合：

- 从集合中选一个数 $p$；
- **选择是否**执行 $x \gets x \oplus p$；
- 从集合中移除 $p$。

Alice 想让最终 $x$ 尽可能大，Bob 想让 $x$ 尽可能小。

已知：值 $2^i$ 出现了 $b_i$ 次（$0 \le i < k$），值 $0$ 出现了 $z$ 次。求双方都绝顶聪明时，最终的 $x$ 值。

**输出**：恰好 $k$ 位二进制数，从高位到低位（即使有前导零也输出）。

---

## 一、问题拆解：每个比特位是独立的

### 1.1 XOR 只影响一位

XOR 运算的作用很简单：一个数 XOR $2^i$，就相当于**翻转**它的第 $i$ 位（0 变 1，1 变 0）。

由于桌面上只有 $0$ 和 $2^i$，每次操作至多影响 $x$ 的**一个**比特位。不同比特位之间互不影响。

> 选 $0$ 时 $x \oplus 0 = x$，什么都不变。所以 $0$ 相当于"空过"一轮。

### 1.2 把 $k$ 个比特位拆成 $k$ 个独立游戏

因为不同比特位不互相干扰，我们可以**逐位分析**。对第 $i$ 位，有 $b_i$ 次"可以决定是否翻转第 $i$ 位"的机会。游戏的实质是：

> 两人轮流决定要不要翻转当前比特位。拿到**最后一次**机会的人，可以最终决定这一位是 $0$ 还是 $1$。

---

## 二、核心结论：三种情况的判定法则

在进入详细分析前，先给出结论——你可以先记住这三条规则，再回头看为什么对：

| 条件          | 第$i$ 位最终值 | 原因                                               |
| ------------- | ---------------- | -------------------------------------------------- |
| $b_i = 0$   | 恒为$0$        | 没有任何机会翻转                                   |
| $b_i = 1$   | 由争夺结果决定   | 两人从高位到低位轮流抢，Alice 抢到高位奇数         |
| $b_i \ge 2$ | 由总步数奇偶决定 | 步数为奇 Alice 全胜（$1$），偶 Bob 全胜（$0$） |

下面我们逐条证明。

---

## 三、$b_i = 0$：无事发生

如果根本没有值为 $2^i$ 的数，那么整局游戏没有机会影响第 $i$ 位。初始 $x=0$，最终第 $i$ 位就是 $0$——毫不意外。

---

## 四、$b_i = 1$：争夺战

### 4.1 为什么是"争夺"

当 $b_i = 1$ 时，第 $i$ 位只有**一次**翻转机会。谁抢到它，谁就拥有了对这一位的最终决定权：

- 如果 Alice 抢到 → 她会在自己回合选 $p=2^i$，执行 XOR → Bit $i = 1$
- 如果 Bob 抢到 → 他会选 $p=2^i$，执行 XOR → Bit $i = 0$
- Alice 拿到 → 这一位 $= 1$
- Bob 拿到 → 这一位 $= 0$

### 4.2 争夺的优先级：高位优先

Alice 和 Bob 都清楚：每个 $b_i = 1$ 的位只能由一个人说了算。但桌上可能同时有好几个 $b_i = 1$ 的位。先抢哪个？

**答案：从高位抢到低位。**

为什么？设想第 $k-1$ 位（最高位，值 $2^{k-1}$）和第 $0$ 位（最低位，值 $2^0$）都是 $b=1$。最高位比所有低位加起来还要大（因为 $2^{k-1} > \sum_{i=0}^{k-2} 2^i$），所以双方一定会先把最高位抢下来。

### 4.3 谁抢到哪个：交替分配

Alice 先手。她的策略是：第一个回合就抢走最高的 $b_i=1$ 位。Bob 在被抢走一个后，余下的回合中，他会优先抢剩下里面最高的那个。Alice 的下一回合抢再下一个……如此交替。

> **图示**（设最高几个 $b_i=1$ 的位是 $i_3 > i_2 > i_1 > i_0$）：
>
> ```
> Alice 第 1 回合 → 抢走位 i3 → 决定 i3 = 1
> Bob   第 1 回合 → 抢走位 i2 → 决定 i2 = 0
> Alice 第 2 回合 → 抢走位 i1 → 决定 i1 = 1
> Bob   第 2 回合 → 抢走位 i0 → 决定 i0 = 0
> ```

规律：**Alice 拿到第 1、3、5… 高位（奇数序号），Bob 拿到第 2、4、6… 高位（偶数序号）。**

## 五、$b_i \ge 2$：总步数决定

### 5.1

当 $b_i \ge 2$ 时，无论这一位此前被反转为何值，在最后一次操作总能将值反转为0或1，因此，该位的值由最后一次操作的玩家决定。

那么，谁拿到最后一次？

### 5.2 步数奇偶性

游戏总回合数 $N = \sum b_i + z$（每个数对应一回合，包括 $0$ 在内）。

- Alice 先手 → 她拿第 $1, 3, 5, \dots$ 回合
- Bob 拿第 $2, 4, 6, \dots$ 回合

**结论**：

- 如果 $N$ 是**奇数**，Alice 拿到最后一回合 → 所有 $b_i \ge 2$ 的位，Alice 都能把最后一次留给自己 → 全部设为 $1$。
- 如果 $N$ 是**偶数**，Bob 拿到最后一回合 → 所有 $b_i \ge 2$ 的位，Bob 都能把最后一次留给自己 → 全部设为 $0$。

易知当总步数为偶数时，一定存在偶数个剩余操作数为奇数的位。
Alice如果操作剩余操作数为奇数的位，Bob可以操作另一个剩余操作数为奇数的位使得剩余操作数为奇数的位仍有偶数个。
Alice如果操作剩余操作数为偶数的位，Bob可以同样操作此位使得此位剩余操作数仍为偶数。
当不存在剩余操作数为奇数的位，Alice被迫操作剩余操作数为偶数的位，使得此位最后一次操作由Bob决定 。
反之同理。

故$N = \sum b_i + z$为奇数时，所有操作数>=2的位均为0，$N = \sum b_i + z$为偶数时，所有操作数>=2的为均为1。

## 六、$0$ 的作用：凑步数

$z$ 个 $0$ 不改变 $x$ 的任何一位，但它们**消耗回合数**。$z$ 的奇偶性直接影响总步数 $N = \sum b_i + z$ 的奇偶性，从而影响 $b_i \ge 2$ 位的胜负。

- 如果 $z$ 使总步数从偶数变奇数 → 相当于送 Alice 一个全局的"最后一手"
- 如果 $z$ 使总步数从奇数变偶数 → 意味着 Bob 拿回全局最后一手

---

## 七、完整算法流程

```
1. 读入 k, z 和 b[0..k-1]
2. 计算 sum = Σb_i
3. 找出所有 b_i == 1 的位置，按 i 排序
4. 从高位到低位，交替分配：
   - Alice 获得最高的 b_i=1 位（标记 ans[i] = 1）
   - Bob 获得次高的（标记 ans[i] = 0）
   - 交替……
5. 判断 (sum + z) % 2：
   - 奇数：Alice 全局制胜
     → 所有未标记位（b_i ≥ 2）设为 1
   - 偶数：Bob 全局制胜
     → 所有未标记位（b_i ≥ 2）设为 0
6. 输出 k 位结果（从高位到低位）
```

### 7.1 复杂度分析

| 步骤                 | 复杂度   |
| -------------------- | -------- |
| 读入                 | $O(k)$ |
| 找出$b_i = 1$ 的位 | $O(k)$ |
| 争夺分配             | $O(k)$ |
| 输出                 | $O(k)$ |
| **总计**       | $O(k)$ |

$k \le 10^5$，$O(k)$ 轻松通过。

## 八、参考代码

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>
#include <vector>
using namespace std;
typedef long long ll;

ll k, z, sum;
int ans[100005];   // -1: 待定, 0: Bob 掌控, 1: Alice 掌控
int cnt[100005];   // b_i
vector<ll> v;      // b_i == 1 的位置

int main() {
    ios::sync_with_stdio(false), cin.tie(0), cout.tie(0);
    memset(ans, -1, sizeof(ans));
    cin >> k >> z;

    for (int i = 0; i < k; i++) {
        cin >> cnt[i];
        sum += cnt[i];
        if (cnt[i] == 1) {
            v.push_back(i);   // 记录 b_i == 1 的位
        }
    }

    // ===== 阶段一：处理 b_i == 1 的位（从高到低交替） =====
    ll sz = v.size();
    bool al = true;  // Alice 先抢
    for (int i = sz - 1; i >= 0; i--) {  // 从高位到低位
        ans[v[i]] = al;
        al ^= 1;  // 交替：Alice → Bob → Alice → Bob
    }

    // ===== 阶段二：总步数奇偶性决定剩余位 =====
    if ((sum + z) % 2) {  // 奇数：Alice 全局制胜
        for (int i = k - 1; i >= 0; i--) {  // 高位到低位输出
            if (cnt[i]) {
                if (ans[i] == -1) cout << "1";  // 未标记，Alice 掌控 → 1
                else if (ans[i] == 0) cout << "0";  // Bob 掌控 → 0
                else cout << "1";  // Alice 掌控 → 1
            } else cout << "0";
        }
    } else {  // 偶数：Bob 全局制胜
        for (int i = k - 1; i >= 0; i--) {
            if (cnt[i]) {
                if (ans[i] == -1) cout << "0";  // 未标记，Bob 掌控 → 0
                else if (ans[i] == 0) cout << "0";  // Bob 掌控 → 0
                else cout << "1";  // Alice 掌控 → 1
            } else cout << "0";
        }
    }
    return 0;
}
```

### 8.1 代码要点

- `ans[i] = -1` 表示该位尚未被"争夺阶段"分配（即 $b_i \ne 1$ 或 $b_i = 0$）
- 争夺阶段（第 31–36 行）：`v` 存储的是位编号 $i$，按 $i$ 从小到大自然有序。`v[sz-1]` 就是最高的 $b_i=1$ 位
- 输出阶段总是从 `k-1` 到 `0`，保证从高位到低位
- 对 $b_i = 0$ 的位始终输出 `"0"`
