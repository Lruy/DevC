# 可能是字符串到签题

[https://oj.internal.blcujszx.cn/problems/2120871721135415297]()

## 题目大意

给定一个字符串 $s$ , 计算 $s$ 中满足任一以下条件的字串数量:

$1.$ 字串的长度为 $1$

$2.$ 字串的第一个字符和最后一个字符在子串中恰出现一次

## 赛时思路

维护每一个字符 $i$ 上一次出现的下标 $a_i$

从前往后遍历 $s$ , 设当前字符为 $j$

显然 $j$ 本身是一个满足条件的字串

而对于每个存在的字符 $i$ , 如 $a_i$ < $a_j$ , 则 $i$ 能与 $j$ 组成一满足条件的字串

累加每个 $j$ 对答案的贡献, 输出即可

时间复杂度 $O(n)$

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>
using namespace std;
typedef long long ll;

ll t,ans;
ll a[26];
signed main(){
    ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
    cin>>t;
    while(t--){
        ans=0;
        for(int i=0;i<26;i++)a[i]=-1; //字符串下标从0开始 如果这里初始化为0会误判在下标0处存在该字符
        ll n;
        cin>>n;
        string s;
        cin>>s;
        for(int i=0;i<n;i++){
            ans++;
            ll idx=s[i]-'a';
            for(int j=0;j<26;j++){
                if(idx==j){continue;}
                else{
                    if(a[j]>a[idx])ans++;
                }
            }
            a[idx]=i; //计算字串数量后再更新a[idx] 否则没有a[j]能够<a[idx]
        }
        cout<<ans<<'\n';
    }
    return 0;
}
```
